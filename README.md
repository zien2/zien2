## Featured work

### [LifeTree](https://github.com/zien2/LifeTree) — planning, growth visualization, and AI analysis

A full-stack planning app that turns goals and daily tasks into a visual “life tree.”

- Create and manage plans with priorities, deadlines, and completion states
- Visualize progress and review trends through analytics
- Built with Next.js, TypeScript, Prisma, MySQL, and Docker
- **Run it:** configure the required values from [`.env.example`](https://github.com/zien2/LifeTree/blob/main/.env.example), then start the app and MySQL with Docker Compose. Full features need a database and secrets.

### [Shop](https://github.com/zien2/Shop) — Vue e-commerce front end

A Vue 3 storefront covering the shopping flow: home, categories, product details, cart, checkout, payment, and member pages.

- Built with Vue 3, Vite, Vue Router, Pinia, and Element Plus
- **Run it:** `npm ci && npm run dev`
- Product and account actions use an external demo API, so end-to-end behavior depends on that service.

### [LLaVA-GM research](https://github.com/zien2/LLaVA-GM) — efficient multimodal modeling

Research on a lightweight LLaVA-style architecture using Gemma, mixture-of-experts (MoE), and staged training for visual question answering.

- [Read the paper](https://www.frontiersin.org/journals/computer-science/articles/10.3389/fcomp.2025.1626346/full)
- The GitHub repository currently contains a research summary only; it does not include runnable code or model weights.
